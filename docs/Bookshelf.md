# Bookshelf

Привет привет!

Тут я расскажу как в Obsidian, на примере книжной полки, можно агрегировать различные данные в единую таблицу.

![[./img/Снимок экрана 2025-06-28 в 16.42.10.png]]

1. Для начала создайте отдельную директорию под книги. Например, `Books`.

2. Дальше мы создаем файл для самой книги. Назвать сам файл можно как угодно, но лучше придерживаться какой-то единой конвенции (например `Автор - Название книги`) для удобства.

3. Затем, есть два варианта

   3.1. руками

   Добавляем в новый файл проперти, с которых будет считывать наша полка данные о книге. Заполняем их.

   ```
     ---
     title: '' // Название книги
     author: '' // Название автора
     pages: '' // Кол-во страниц
     status: '' // Текущий статус
     created: 2025-06-23 // нужно будет проставить тип данных Date и появится удобный календарь
     ---
   ```

   3.2. шаблоном

   чтобы не делать эти поля руками, в Obsidian есть встроенный плагин `Templates`, который позволяет вставлять шаблон.

   - кладем шаблон в директорию `Templates` (это дефолтная директория для шаблонов, откуда будет подтягиваться они)

   - нажимаем `Cmd + P` (на mac) или `Ctrl + P` или `Ctrl + Shift + P` (на винде)

   - начинаем вводить `Templates: Insert template`, в списке появится комманда, нажимаем на нее (в будущем она будет в самом начале при частом использовании)

   - далее из списка выбираем нужный шаблон

   - на странице должна появиться заготовка

4. Cоздаем файл книжной полки, в котором мы будем собирать все наши книги. Например, `Bookshelf`.

вставляем этот скрипт (при копировании может захватить лишние кавычки ```` в начале и в конце, их нужно убрать)

````
```dataviewjs
const getBookName = (book) => {
  const author = Array.isArray(book?.author) ? book?.author[0] : book?.author;

  return `${book?.title} - ${author || '-'}`
}

let pages = dv.pages('"Books"')
  .where(p => !['Bookshelf', 'Books'].includes(p.file.name))
  .array();

const TABLE_TITLES = [
  "№",
  "Название",
  "Статус",
  "Страниц",
  "Дата прочтения",
];

dv.table(TABLE_TITLES,
  pages.map((p, index) => [
    index + 1,
    getBookName(p),
    p.status ?? "—",
    p.pages ?? 0,
    p.created ?? "—",
  ])
);

let totalBooks = pages.length;

const READED = "прочтено";

let readBooks = pages.filter((p) => p.status?.toLowerCase() === READED).length;

let totalPages = pages.reduce((sum, p) => {
  if (p.status !== READED) return sum;

  return sum + (Number(p.pages) ?? 0)
}, 0);

dv.paragraph(`
-----
**Итого:**
📚 Всего книг: **${totalBooks}**

✅ Прочтено: **${readBooks}**

📄 Всего страниц: **${totalPages}**`);
```
````

Пояснения по скрипту

1. функция которая отображает название автора и книги

```js
const getBookName = (book) => {
  const author = Array.isArray(book?.author) ? book?.author[0] : book?.author;

  return `${book?.title} - ${author || "-"}`;
};
```

так как я использую два вида вставки и ручное и шаблонное, то порой в шаблоне в поле автор приходит массив, поэтому делаю проверку.

2. функция которая получает массив страниц

```js
let pages = dv
  .pages('"Books"')
  .where((p) => !["Bookshelf", "Books"].includes(p.file.name))
  .array();
```

в строчке с `.where` я отфильтровываю саму книжную полку и корней компонент для директории, чтобы они не входили в выборку для отображении на странице

3. тут создается таблица

```
const TABLE_TITLES = [
  "№",
  "Название",
  "Статус",
  "Страниц",
  "Дата прочтения",
];
```

```js
dv.table(
  TABLE_TITLES,
  pages.map((p, index) => [
    index + 1,
    getBookName(p),
    p.status ?? "—",
    p.pages ?? 0,
    p.created ?? "—",
  ])
);
```

массив `TABLE_TITLES` это заголовки таблицы.

```js
[index + 1, getBookName(p), p.status ?? "—", p.pages ?? 0, p.created ?? "—"];
```

это поля таблицы, которые соответствуют индексу названия поля, пример:
`№ -> index + 1`,
`Название -> getBookName(p)`.

4. всего книг

```js
let totalBooks = pages.length;
```

это кол-во всех книг в списке, значение которого пойдет в
`📚 Всего книг: **${totalBooks}**`

5. отметка о статусе книги

```js
const READED = "прочтено";

let readBooks = pages.filter((p) => p.status?.toLowerCase() === READED).length;
```

если в поле `status` будет другое слово, то оно не будет считать книгу прочитанной. Если есть необходимость в другом русскоязычном статусе, например, `готово`, то переменная `READED`, тоже должна содержать тоже значение.

6. получение всех прочитанных страниц.

```js
let totalPages = pages.reduce((sum, p) => {
  if (p.status !== READED) return sum;

  return sum + (Number(p.pages) ?? 0);
}, 0);
```

Сюда не попадают книги чей статус не прочитан.

7. итоговый вывод инфы

```js
dv.paragraph(`
-----
**Итого:**
📚 Всего книг: **${totalBooks}**

✅ Прочтено: **${readBooks}**

📄 Всего страниц: **${totalPages}**`);
```
